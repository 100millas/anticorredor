# Fuerza estructural · Seguimiento

App web de un solo archivo (`index.html`) para registrar el entrenamiento de fuerza para corredores: sesiones por fase, series con peso, repeticiones y RIR, historial, progreso, ratios de equilibrio estructural y planificador semanal.

- Funciona sin conexión y sin cuenta.
- Los registros se guardan solo en el navegador de cada dispositivo. Usa **Ajustes → Exportar copia** para guardar una copia de seguridad.
